# 🌟 Poornima Mendhekar - Personal Portfolio

Welcome to the official source code repository for **Poornima Mendhekar's Personal Portfolio Website**. Designed with a luxurious **Warm Obsidian & Gold Dark Mode Aesthetic**, custom typography, and high-performance interactive features.

## ✨ Features & Sections

- **👤 Hero Section**: Interactive 3 rotating gold rings circular portrait frame, typing name animation, quick location badge, social links, and resume download.
- **⚡ Skills & Expertise**: 6 vertical skill card containers featuring single-line no-wrap badges for Programming Languages, AI/ML/GenAI & NLP, Data Science & Analytics, Web Development, Databases, and Tools & Cloud Platforms.
- **🏆 Professional Certifications**: 7 square certification cards matching reference aesthetics with direct credential verification links (ServiceNow CSA & CAD, Oracle Database Foundations, Red Hat RH124, Google Cloud Foundations, Power BI Infosys Springboard).
- **💼 Work Experience**: Wide timeline containers (`1140px`) with company badges, single-line bullet highlights, and direct GitHub project links.
- **🚀 Featured Projects**: 5 highlighted projects (*AI-Powered Loss Description Generator, Student Finance Management Platform, IoT Smart Dustbin with Automated Lid, AgriFusion Crop Intelligence, IoT Real-Time Speech-to-Speech Translation System*) equipped with tech tags, live demo buttons, and GitHub repository links.
- **📜 Publications & Patents**: 3 published items featuring official patent journal publication, Scopus indexed paper, and AUTOCOM 2025 conference paper with top-right corner "View Publication" buttons.
- **📬 Contact & FormSubmit Integration**: Compact, sleek contact form powered by asynchronous FormSubmit AJAX for instant messaging.
- **⬆️ Floating Back-to-Top Button**: Smooth scroll navigation button in the bottom-right corner.

## 🚀 Local Development Setup

To run this portfolio locally on your machine:

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/poornima2707/Portfolio_poornima.git
   cd Portfolio_poornima
   ```

2. **Serve locally**:
   - Double-click `index.html` to open directly in any modern browser.
   - Or run a lightweight HTTP server:
     ```bash
     python -m http.server 8080
     ```
     Then open `http://localhost:8080` in your web browser.
